Bandeja de Clientes

  1. Cada formulario se guarda automáticamente en clientes.
  2. La bandeja actualiza en tiempo real.
  3. Puede cambiar estado, agregar notas y exportar a CSV.
  4. Solo administradores pueden modificar el estado.
Regla clave: allow create: if true y allow update, delete: if request.auth != null.

Agenda y avisos a clientes

  1. La agenda guarda eventos en la colección agenda.
  2. Cuando falten menos de 24 horas, el panel mostrará una alarma visual.
  3. El botón WhatsApp abre el chat del cliente con el mensaje listo para enviar.
  4. Al crear un evento vinculado a una consulta, aparece un ícono verde de calendario en la bandeja.
El modo incluido es manual asistido: genera el mensaje y abre WhatsApp.
